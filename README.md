# 公開假資料技術展示

此獨立測試站僅展示輪播與 PDF 閱讀器，不是正式網站。圖片、文件與分班內容皆為合成假資料；範例外部連結不代表正式服務。

- 固定公開候選：v2.6a-public-r1；原 200 個執行期檔案保持不變。
- 不包含管理端、草稿、快照、內部 QA、帳號、金鑰或正式業務資料。
- 使用同源相對路徑；需透過 HTTP(S) 使用，不宣稱下載後 file:// 可直接執行。
- 正式資料測試前另行確認託管與存取限制，本 repo 不用於正式資料。
